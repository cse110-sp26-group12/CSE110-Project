# User Stories

## Kelly (Team Lead)
- As a [team lead], I want [a dashboard that shows each team member’s most recent status update and current blocker (if applicable)] so that [I can identify who needs help without asking frequently and before stand-ups].
- As a [team lead], I want [color indicators for each member’s overall progress], so that [I can quickly spot who is off track or falling behind, without having to read every update].
- As a [team lead], I want [to receive notifications when someone marks themselves as ‘blocked’] so that [I can assist in unblocking the problem immediately].

## James (Struggling Team Member)
- As a [developer (who struggles to speak up)], I want [an option to mark a blocker without my name being visible to the whole team], so that [I can ask for help without feeling embarrassed].
- As a [developer], I want [a simple form with suggested solutions] so that [I have help but don’t have to ask for it].
- As a [developer], I want [to update my status with a few clicks quickly], so that [I don’t procrastinate on checking in].

## Jason (The Commuter)
- As a [remote team member], I want [to see threaded comments/summaries on each task] so that [I don’t miss context from conversations I wasn’t a part of].
- As a [remote team member], I want [a weekly history of each person’s updates], so that [I can catch up on information that I didn’t get in person].
- As a [remote team member], I want [to receive a daily summary notification], so that [I stay informed and don’t have to keep checking the website constantly].

## Paula (Not-So Tech Savvy)
- As a [non-technical user], I want [simple buttons and instructions], so that [I know exactly where to go and don’t get confused searching the site].
- As a [non-technical user], I want [simple text boxes without complex jargon], so that [I understand what I’m reading].
- As a [non-technical user], I want [tooltips that explain each field], so that [I know what to write without guessing].
- As a [non-technical user], I want [a confirmation message], so that [I know what I worked on was saved].
