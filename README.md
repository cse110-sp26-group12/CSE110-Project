## Local Development Setup




1. Install Node.js 20+
2. Clone the repository
3. Install dependencies

```bash
npm install
```

It might download a lot of files but it's ok don't be scared.

4. Run quality checks

```bash
npm run lint
npm test
npm run format:check
```
