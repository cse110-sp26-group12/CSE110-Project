How it works

A Cloudflare Worker hits the GitHub REST API every 5 minutes for events on the team repo. Each member's commits and PRs are matched to their check-in by GitHub username, then offered as autocomplete suggestions when they fill out "yesterday."

→ No backend, no database, no servers.
